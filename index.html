Code cave e trampolim
Desvio por chamada de função: a instrução não é apagada — ela é movida para uma região de memória limpa. No lugar dela entra um salto; o programa executa o código inserido, a instrução original realocada e retorna.
Programa íntegro, sem a chamada. Ponteiro na Instrução 1 — play desce reto, uma instrução por vez.
Code cave — um trecho de espaço livre e não utilizado dentro do próprio executável (em geral o preenchimento que sobra do alinhamento das seções em memória). Como já está ali, vazio, dá para escrever código novo nele sem empurrar nem deslocar o resto do programa. É a "região de memória limpa" do diagrama.
Trampolim — o desvio que faz a execução "quicar" para outro lugar e voltar. No lugar da instrução original entra um salto (a chamada) para a code cave; lá o programa roda o código inserido, executa a instrução original que foi guardada e então retorna ao ponto seguinte. O nome vem justamente desse ir-e-voltar.
